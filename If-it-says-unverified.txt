If your computer says Sreon is unverified or can't be opened

This is expected. Sreon is open source and not signed with Apple or Microsoft certs. The OS warning is not a virus scan.

Mac - Installer DMG:
The DMG contains Sreon.app and Sreon Installer.app with beautiful UI.
1. Open Sreon.dmg. You will see Sreon on left, Sreon Installer below it, Applications on right, with purple arrows.
2. Option A - Drag: Drag Sreon to Applications. Sreon then appears in Applications and Launchpad.
3. Option B - Installer with UI: Double-click Sreon Installer.app. It shows loading and installs to Applications with one click. After install, it shows Open Sreon button. Sreon appears in Applications.
4. If DMG won't open: Control-click Sreon.dmg -> Open -> Open. Or Terminal: xattr -dr com.apple.quarantine ~/Downloads/Sreon.dmg  Then: hdiutil attach ~/Downloads/Sreon.dmg -noverify
5. If app says unverified after dragging: Applications -> Control-click Sreon -> Open -> Open (once). Or System Settings -> Privacy & Security -> Open Anyway. Or Terminal: xattr -dr com.apple.quarantine /Applications/Sreon.app
6. PKG alternative: Double-click Sreon.pkg, it installs to Applications automatically and appears in Applications.

Mac - After install:
Sreon appears in Applications, Launchpad, Spotlight. Open from there. First launch may need Control-click -> Open.

Windows - Installer:
1. Run SreonSetup.exe (or Sreon Installer). Beautiful installer with loading shows progress.
2. It installs to Program Files\Sreon and creates Start Menu shortcut Sreon -> appears in Start Menu and Apps list.
3. After install, Sreon appears in Start Menu. Open from there.
4. If SmartScreen says Windows protected your PC: Click More info -> Run anyway.
5. If blocked: Right-click SreonSetup.exe -> Properties -> Unblock -> OK.
6. Portable fallback: If installer fails, use Windows/Sreon.exe directly.

Linux - Installer:
1. DEB: sudo dpkg -i sreon.deb  Then Sreon appears in Applications menu.
2. Or run Sreon Installer (Qt UI) - it installs to ~/.local/share/sreon and creates ~/.local/share/applications/sreon.desktop, so Sreon appears in Applications.
3. Or AppImage: chmod +x Sreon.AppImage && ./Sreon.AppImage
4. If FUSE error: ./Sreon.AppImage --appimage-extract-and-run
5. Or tar.gz: unpack and run ./Sreon/Sreon

All builds include this file. Same guide is in Help -> If Sreon is unverified inside browser and in HOW-IT-WORKS.md.
