If your computer says Sreon is unverified or can't be opened

This is expected. Sreon is open source and is not signed with an Apple Developer certificate or Microsoft publisher certificate. The warning comes from the operating system, not from a virus scan.

Mac - Sreon.dmg won't open at all:
1. Try Control-click Sreon.dmg -> Open -> Open.
2. If it says damaged or no mountable file systems, open Terminal and run:
   xattr -dr com.apple.quarantine ~/Downloads/Sreon.dmg
   Then double-click again. Use the real path to your file.
3. If still not opening, try in Terminal:
   hdiutil attach ~/Downloads/Sreon.dmg -noverify
   Then open /Volumes/Sreon and drag Sreon to Applications.
4. If you have Sreon.app.zip in the download, unzip it and drag Sreon.app to Applications. Same unverified steps apply.

Mac - drag area:
The DMG window has a purple header that says Drag Sreon to Applications, a cream tray, Sreon on the left, Applications on the right, and a purple arrow. Drag Sreon onto Applications. The window also shows what to do if it says unverified.

Mac - Sreon app says unverified after dragging:
1. Open Applications, Control-click Sreon -> Open -> Open. You only do this once.
2. If it still refuses: System Settings -> Privacy & Security -> scroll down -> Open Anyway.
3. If it says damaged: xattr -dr com.apple.quarantine /Applications/Sreon.app

Windows - SmartScreen:
1. When you see Windows protected your PC, click More info, then Run anyway.
2. If Windows says file is blocked: right-click Sreon.exe -> Properties -> check Unblock -> OK, then open.
3. Keep Sreon.exe and its folder together. Do not run from inside the zip.

Linux - AppImage:
1. chmod +x Sreon.AppImage
2. ./Sreon.AppImage
3. If FUSE error: ./Sreon.AppImage --appimage-extract-and-run
4. Or unpack Sreon-linux.tar.gz and run ./Sreon/Sreon

All builds include this file. Same steps are in Help -> If Sreon is unverified inside the browser and in HOW-IT-WORKS.md.
