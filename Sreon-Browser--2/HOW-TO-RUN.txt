HOW TO RUN SREON
==============

FASTEST WAY (no typing)
---------------------------------------------------------------
1. Install Node.js (https://nodejs.org, LTS button) and Rust
   (https://rustup.rs) — only once, ever. Restart your computer's
   Terminal/Explorer after installing these if it was already open.

2. Double-click:
     - Mac/Linux: "Start Sreon (Mac or Linux).command"
     - Windows:   "Start Sreon (Windows).bat"

   The first run installs a few things and compiles some Rust code,
   so it can take a few minutes — you'll see text scrolling by, that's
   normal, just wait. A Sreon window opens when it's done.

   Every run after the first is much faster. If you copy this folder to
   a different computer, the first run there will automatically detect
   that and reinstall cleanly rather than launching with the wrong
   platform's files.

macOS "unidentified developer" warning
---------------------------------------------------------------
Right-click "Start Sreon (Mac or Linux).command" and choose "Open" once,
then click "Open" again in the dialog. After that, double-clicking
works normally.

MANUAL WAY (Terminal), if you prefer it
---------------------------------------------------------------
cd path/to/Sreon-Browser/app
npm install
npm run dev

OPTIONAL — build a real installable app
---------------------------------------------------------------
cd app
npm run build

This creates the finished app inside:
app/src-tauri/target/release/bundle/

An icon is already included, so there's no separate icon-generation
step needed before building.

Sreon builds natively for the OS you run this on — there's no
cross-compiling required, but you do need a few one-time system
prerequisites per platform:

WINDOWS
  1. Install Node.js LTS (https://nodejs.org).
  2. Install Rust (https://rustup.rs) — pick the default options.
  3. Install "Desktop development with C++" from the Visual Studio
     Build Tools (https://visualstudio.microsoft.com/visual-cpp-build-tools/) —
     Tauri needs the MSVC linker. Free, no full Visual Studio needed.
  4. Restart your terminal, then follow "MANUAL WAY" above.
  `npm run build` produces an .msi installer and a .exe under
  app/src-tauri/target/release/bundle/.

MACOS
  1. Install Node.js LTS (https://nodejs.org).
  2. Install Rust (https://rustup.rs).
  3. Install Xcode Command Line Tools: open Terminal and run
     `xcode-select --install`.
  4. Follow "MANUAL WAY" above.
  `npm run build` produces a .app bundle and a .dmg installer under
  app/src-tauri/target/release/bundle/. To share the .dmg with
  others, they'll see the same "unidentified developer" warning
  described above unless you code-sign it with an Apple Developer
  account — optional, only needed for wide distribution.

LINUX
  1. Install Node.js LTS (https://nodejs.org) and Rust
     (https://rustup.rs).
  2. Install the WebView/build dependencies Tauri needs. On
     Debian/Ubuntu:
       sudo apt update && sudo apt install -y libwebkit2gtk-4.1-dev \
         build-essential curl wget file libxdo-dev libssl-dev \
         libayatana-appindicator3-dev librsvg2-dev
     On Fedora:
       sudo dnf install webkit2gtk4.1-devel openssl-devel curl wget \
         file libappindicator-gtk3-devel librsvg2-devel
     On Arch:
       sudo pacman -S --needed webkit2gtk-4.1 base-devel curl wget \
         file openssl appmenu-gtk-module libappindicator-gtk3 \
         librsvg
  3. Follow "MANUAL WAY" above.
  `npm run build` produces a .deb, an .rpm (if rpmbuild is present),
  and an .AppImage under app/src-tauri/target/release/bundle/ — the
  AppImage runs on most distros without installing anything.

TROUBLESHOOTING
---------------------------------------------------------------
"Could not read package.json"
  -> You're in the wrong folder. Make sure you're inside "app",
     not the outer "Sreon-Browser" folder.

"Missing script: tauri"
  -> Use "npm run dev", not "npm run tauri dev".

Forgot your Sreon app-lock password
  -> On the lock screen, click "Forgot password?" and confirm. This
     removes just the lock — your tabs, history, and saved logins are
     untouched. See PRIVACY.txt for why there's no other way to
     recover it.
