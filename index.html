How to install on Mac +
  1. Download the Mac installer above, then open SREONBROWSER.dmg from your Downloads folder.
  2. Drag Sreon into your Applications folder, then eject the disk image.
  3. Open Sreon from Applications.

If macOS can’t verify the app

A message such as “Apple cannot check it for malicious software” or “developer cannot be verified” can appear for apps that Apple hasn’t verified. It isn’t proof of malware, but it isn’t a guarantee of safety either.

Only continue if you downloaded Sreon from this official site and trust the app:

  1. After trying to open Sreon, go to System Settings → Privacy & Security.
  2. Scroll down to the Security section and find the message about Sreon being blocked.
  3. Click Open Anyway, authenticate if asked, and confirm Open.

If Open Anyway isn’t shown, try opening Sreon once more and check the settings again. On a managed Mac, contact your administrator.

Sreon for Linux

For those who make it their own.

Coming soon · Download not yet available
How to install on Linux +
  1. Download the Linux installer above, then check that your system is ARM64: dpkg --print-architecture should print arm64.
  2. Install it with sudo apt install ./SREONBROWSER-linux-arm64.deb (or sudo dpkg -i the same file).
  3. Sreon’s SPRFST payload lands in /opt/sreon — engine sources, standard library, examples, and the Guidebook. Run sreon in a terminal to see what is ready.

About the Linux engine

The native engine binaries from the macOS build are Mach-O executables and cannot run on Linux, so this package ships Sreon’s full portable payload with a launcher instead. When a linux-arm64 engine build is published, place it in /opt/sreon/bin and sreon will start it. Until then, the payload is yours to read and make your own.

A FEW GOOD QUESTIONS

Curious?
Good.

What makes Sreon different?+

Sreon pairs a minimal browsing experience with a programmable foundation. It’s built entirely on SPRFST, a self-made language, and includes Studio so the browser can become your own creative workspace.

Do I need to code to use Sreon?+

No. The idea is a calm, focused browser from the start. Studio is there when you want to go further — not something you need to use to browse.

What is SPRFST?+

SPRFST is the custom language behind Sreon. It’s the foundation of the browser, rather than an extension language added on top. The playground above is an illustrative preview of the customization experience, not a live compiler.

When can I download it?+

Sreon is available for Mac and Linux (ARM64), with Windows ready for a future release. You’ll find the official links in the download section right here.
